# Test plan

Legend. **[C]** = I walked through the code and expect this result (still worth one browser run). **[B]** = you must test in the browser: the code was not
supplied (Sessions 8-9) or it depends on Apache, the browser or the clock. Use a **copy** of the database with the sample seed
(`wmsu_garment_shop.sql`), and run the patcher and migration 008 first. Sample logins: set passwords with `php tools/set_password.php <user> "<password>"`.

Sample facts used below: `PRI-BOY-POLO` (auto, cap 5), `JHS-PE-SHIRT` (approval, cap 3), `TER-CS-POLO` (approval, cap 3), `PRI-GIRL-BLSE` size 12 (out of stock, waitlist
entry exists), toga `TOGA-BACH` (rental). Seed student `2021-00555` (Grace Lim) already has a released toga this period.
